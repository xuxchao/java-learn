# Triage Labels（分拣标签）

相关 skill 使用五个标准分拣角色（triage roles）来描述问题。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整描述，可交由 AFK agent（后台智能体）处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当某个 skill 提到某个角色（例如"应用 AFK-ready 分拣标签"），使用本表中对应的标签字符串。

如需使用其他词汇，可修改右列以匹配你实际使用的命名。
