# 按功能学：Java 后端面试学习路线图（优化版 v2）

> 主线：电商/秒杀系统。每个功能模块 = 一个学习单元，单元内按「原理(八股) → 小练习 → 自测题」三步推进。
> 时间窗：1–3 个月紧凑。档位：**T1 死磕 / T2 覆盖 / T3 后补**。
> 基线：Java 17 + Maven + IntelliJ IDEA + Spring Boot 3.x + Docker（本地基建）。
> 优化点（v2）：M2 提前、补计算机基础轨道、算法用 Java、Mock 节奏前置、就绪门禁、Docker 基建、求职软技能轨道。

## M1 工程脚手架 & Spring Boot 原理（T1，W1–W3）

- **功能**：搭多模块 Maven 工程，定义 controller/service/mapper 分层，统一返回体 + 全局异常处理，写第一个 REST 接口；用 Docker Compose 起 MySQL/Redis。
- **原理/八股**：Java 17 现代语法（Stream/Optional/var/record/sealed/switch 表达式，你 8 年没碰重点补）；Spring Boot 自动装配（@SpringBootApplication→@EnableAutoConfiguration→spring.factories）；IOC、Bean 生命周期与循环依赖（三级缓存）；AOP（JDK 动态代理 vs CGLIB、@Transactional 失效）；@ControllerAdvice、@Validated。
- **小练习**：手写用户查询接口（分页/校验/统一返回），讲清 Bean 如何被创建注入。
- **自测题**：@Autowired 与 @Resource 区别？@Transactional 哪些情况失效？自动装配大致流程？

## M2 用户注册登录 & 鉴权（T1，W1–W3，已提前）

- **功能**：注册（BCrypt 加密）、登录（JWT 签发）、拦截器鉴权、RBAC。
- **原理/八股**：HTTP/HTTPS、Cookie/Session vs JWT 取舍；过滤器 vs 拦截器 vs AOP 执行顺序；Spring Security 认证/授权/过滤器链；BCrypt 防爆破、令牌续期。
- **小练习**：JWT + 拦截器实现登录态校验，对比 Session 方案讲清取舍。
- **自测题**：JWT 与 Session 怎么选？三者执行顺序？RBAC 怎么设计？

## M3 商品 & 数据库持久化（T1，W3–W6）

- **功能**：商品表设计、MyBatis-Plus CRUD、库存字段、事务下单。
- **原理/八股**：InnoDB；索引 B+ 树、聚簇/二级索引、回表、最左前缀、覆盖索引；事务 ACID、隔离级别、MVCC、间隙锁防幻读；乐观锁（版本号）vs 悲观锁（for update）；MyBatis #{} vs ${}、缓存、插件；连接池 HikariCP；SQL 优化（explain、索引失效）。
- **小练习**：设计商品+库存表，写带事务的下单扣库存，故意制造索引失效并 explain 验证。
- **自测题**：RR 为何还可能幻读？最左前缀怎么生效？#{} 为何防注入？

## M4 商品列表 & 缓存（T1，W3–W6）

- **功能**：热点商品放 Redis，读缓存写回库，处理一致性。
- **原理/八股**：Redis 数据结构与适用；RDB vs AOF；缓存穿透（布隆过滤器/空值）、击穿（互斥/逻辑过期）、雪崩（随机 TTL/集群）；一致性（先更 DB 再删缓存 + 延迟双删）；分布式锁（Redisson 看门狗）为 M5/M8 铺垫。
- **小练习**：商品详情接 Redis，手写穿透/击穿防护。
- **自测题**：三大问题各自解法？一致性怎么保证？分布式锁为何要过期 + 校验持有者？

## M5 购物车 & 并发（T1，W3–W6 穿插）

- **功能**：并发下单、库存并发扣减、接口幂等。
- **原理/八股**：线程/synchronized/volatile（可见性/有序性，不保原子）；JUC（Atomic/CAS/ABA、AQS、ReentrantLock、ConcurrentHashMap）；线程池七大参数/拒绝策略/Executors 隐患；幂等（token/唯一索引/状态机）。
- **小练习**：线程池 + 锁模拟 100 并发扣库存，对比 synchronized/ReentrantLock/乐观锁。
- **自测题**：volatile 保什么不保什么？线程池参数怎么定？高并发库存为何用乐观锁？

## M6 下单 & 消息队列（T2，W6–W8）

- **功能**：下单后异步发 MQ、扣库存解耦、订单状态机。
- **原理/八股**：Kafka vs RocketMQ；消息可靠性（不丢/不重/有序）；死信队列、重试、事务消息。
- **小练习**：下单成功发 MQ，消费者幂等处理同一订单不重复扣减。
- **自测题**：MQ 怎么保不丢不重？顺序消息怎么实现？事务消息原理？

## M7 支付 & 分布式事务（T2，W8–W10）

- **功能**：支付回调、跨服务最终一致。
- **原理/八股**：CAP/BASE；2PC/TCC/Saga/事务消息；Seata（TC/TM/RM）。
- **小练习**：事务消息实现"下单→扣库存→支付"最终一致。
- **自测题**：CAP 为何不能三角全要？TCC 三阶段？何时该/不该用分布式事务？

## M8 秒杀 & 高并发（T2，W8–W10）

- **功能**：秒杀接口：限流 + Redis+Lua 原子扣库存 + MQ 异步落单。
- **原理/八股**：限流（令牌桶/漏桶/滑动窗口；Sentinel）；熔断/降级/隔离；库存预热、热点 key 隔离、Lua 原子；压测思维（QPS/RT/拐点）。
- **小练习**：简化秒杀（Lua 扣库存 + 令牌桶限流 + 异步下单）。
- **自测题**：三种限流算法区别？熔断与降级区别？秒杀为何用 Redis+Lua 而非 DB 事务？

## M9 微服务化（T2，W8–W10 起）

- **功能**：按"用户/商品/订单"拆服务，接入注册发现与网关。
- **原理/八股**：Spring Cloud（Nacos/Eureka、Gateway、Sentinel、Config）；服务拆分边界、OpenFeign RPC、负载均衡；链路追踪（Sleuth/Micrometer）。
- **小练习**：把工程拆 2–3 服务，跑通一次跨服务调用。
- **自测题**：何时该拆/过度设计？网关做什么？注册发现解决什么？

## M10 系统设计 & 算法冲刺（T2/T3，W10–W12）

- **功能**：高频设计题 + LeetCode 中等节奏收尾。
- **内容**：短链/限流/排行榜/Feed/秒杀架构；高可用套路（缓存/异步/分库分表/CDN/冗余）。
- **自测题**：千万 QPS 计数/排行榜怎么设计？秒杀架构画得出来吗？
